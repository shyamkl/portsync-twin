# portsync-twin
Real-Time Multimodal Port Congestion &amp; Intermodal Evacuation Digital Twin for the NLDSL Grand Challenge.
## 🛠️ System Technology Stack & Architecture
- **Frontend Core Canvas:** React.js framework initialized via Vite engine, mapped using standard responsive flex dark-mode grids.
- **Geospatial Mapping Overlay Layer:** Leaflet Mapping API integration (`react-leaflet`) centered precisely over JNPT logistics hub coordinates.
- **High-Speed Asynchronous API Backend Router:** Python FastAPI web framework deploying fully decoupled async/await database transaction pipelines.
- **Persistent Data Store Layer:** MySQL database cluster mapping high-performance indexing across real-time `assets_telemetry` record cycles.
